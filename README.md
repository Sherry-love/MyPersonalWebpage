## 引子

我觉得作为一个计算机专业的学生一定要有一个自己的个人网站，不然都不好意思说自己是计算机的学生。

另外，由于我迫切地需要进行一个自己的个人项目，但苦于没有思路，不知道去做什么。

在这两种原因的驱使下，我决定选择个人网页来作为我的第一个项目。

我生活在一个极其幸福的时代，知识的获取极其便捷，并且有了 AI 的帮助，很多事情可以做到事半功倍。

我对这个网页的设计理念是尽量简约，配色也尽量选择淡一些的，内容的话是想到什么就加什么。

总是听别人说要先把手弄脏，要在实践中学习。

之前我总是期望一切都准备好再出发，现在，我想试试新的方式。

写到这，我想到了贴吧上的一个帖子下面的一段话：

> 人就是这样，想来想去，犹豫来犹豫去，觉得自己还没准备好，勇气没有攒够，
>
> 其实只要迈出去了第一步，你就会发现一切早就已经准备好了。

做一件事最重要的是什么？当然是先去做。

我确信，在我前进的过程中，我想要的一切都会到来的。

## 项目介绍

一个以印象派画作为色彩意象的个人主页：淡紫、淡粉、雾青的毛玻璃卡片，配上缓慢漂移的光斑与极轻的动效。

**技术栈**

- React 18 + TypeScript
- Vite 5 构建
- Tailwind CSS 4（构建期集成，不再依赖 CDN）
- 字体与图标全部本地托管：Font Awesome 7 + Fontsource + 中文子集字体
- 天气数据来自 open-meteo（免费、无需 key，按 30 分钟缓存在本地）
- GitHub Pages 自动部署（GitHub Actions）

**几个自己比较喜欢的部分**

- **此刻的青岛**：按本地时间换整站光线（破晓 / 清晨 / 白昼 / 黄昏 / 夜色），再叠加青岛的实时天气——下雨就下雨，下雪就下雪。没有任何按钮，打开就是「此刻」。
- **物件化**：关于我是摊开的手账，技术栈是沾着颜料的调色盘，奖项挂在木质画框里，爱好是散在桌上的拍立得，项目是一排可以抽出来的书。
- **代码花园**：Canvas 手绘 53×7 贡献热力图，一条小蛇沿贪心路径巡游、吃掉格子、解体成粒子再重生。数据来自真实 GitHub 贡献（构建期抓取快照，不做随机伪造）。
- **平台轨道**：GitHub / LeetCode / 牛客 / Kaggle / 洛谷 五个图标绕中心声呐公转。
- **流态旋转时间轴**：开发记录沿圆环缓慢公转，悬停暂停；手机上自动降级成竖直时间轴。
- **小练笔**：自动加载 `src/essays/*.md`，卡片原地展开、逐段打字机、阅读进度条。
- **相册**：青岛的公共影像与莫奈的公有领域作品，瀑布流排布，点开可看大图、作者与许可；自己的照片放进 `design/photos/` 就能混进去。
- **词云**：技术栈右边的一个小 3D 球，36 个词在球面上缓慢旋转；拖拽换角度，悬停看分类，点词去对应页面。
- **四季树**：标题上方的小树，基于 B 站 @再来一瓶辣椒酱 的教程工程渲染的 12 秒四季循环；首屏只加载视频，不跑实时 3D。
- **小幽灵岛**：代码花园右侧的小岛，幽灵会在树前左右游走（3 秒循环），不是静态贴纸。

**藏在角落里的东西**

- `↑↑↓↓←→←→BA`：整站被画笔搅过 5 秒。
- 404 页面有一只跟着鼠标飞的萤火虫，点它会带你回去。
- 偶尔会有一只蜗牛爬到页面上，戳一下会缩回壳里。

## 项目文件注释

- 根目录：`index.html`、`vite.config.ts`、`README.md`
- `public/`：favicon、分享图、`images/`、`gallery/`、GitHub Pages 的 `404.html`
- `src/`
  - `components/`：所有 UI 组件
  - `pages/`：六个页面
  - `ambient/`：时间与天气的「此刻」状态
  - `data/`：项目、时间线、贡献快照等结构化数据
  - `essays/`：小练笔的 Markdown 原稿
  - `assets/fonts/`：构建出来的中文子集字体
  - `styles/`：物件与彩蛋的样式
- `scripts/`：贡献数据抓取、相册抓取、图片处理、字体子集化；`scripts/blender/` 是四季树的建模与渲染脚本
- `design/`：原始图片 + `blender/`（四季树场景与渲染中间文件）
- `docs/`：部署与维护说明
