## 引子
我觉得作为一个计算机专业的学生一定要有一个自己的个人网站，不然都不好意思说自己是计算机的学生。

另外,由于我迫切地需要进行一个自己的个人项目，但苦于没有思路，不知道去做什么。

在这两种原因的驱使下，我决定选择个人网页来作为我的第一个项目。

我生活在一个极其幸福的时代，知识的获取极其便捷，并且有了AI的帮助，很多事情可以做到事半功倍。

我对这个网页的设计理念是尽量简约，配色也尽量选择淡一些的，内容的话是想到什么就加什么。

总是听别人说要先把手弄脏，要在实践中学习。

之前我总是期望一切都准备好再出发，现在，我想试试新的方式。

写到这，我想到了贴吧上的一个帖子下面的一段话：

> 人就是这样，想来想去，犹豫来犹豫去，觉得自己还没准备好，勇气没有攒够，
> 
> 其实只要迈出去了第一步，你就会发现一切早就已经准备好了。

做一件事最重要的是什么？当然是先去做。

我确信，在我前进的过程中，我想要的一切都会到来的。

## 项目介绍
这是一个现代前端项目，采用以下技术栈：
* React + TypeScript
* Vite 作为构建工具
* 组件化架构（所有UI拆分为独立组件） 
* 包含动画/交互效果

## 内容介绍
1. 个人信息（姓名，学历，联系方式，个人简介）
2. 技术栈
3. 一些平台（b站，知乎，抖音，LeetCode，洛谷，GitHub，牛客网，Kaggle）
4. 一些奖项
5. 个人爱好
6. 个人项目介绍

## 需要说明的是
1. 大部分是Gemini和DeepSeek写的，自己只做了很小一部分的修改 。
2. 在这个项目是我大二上学期开始做的，一开始我一点前端的知识也不理解，一点也没有学，并且我也没有学习的想法。
   如果我开始学习前端的知识，我会记录说明。
