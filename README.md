# 我的个人网页

## 项目介绍：
这是一个现代前端项目，采用以下技术栈：
* React + TypeScript
* Vite 作为构建工具
* 组件化架构（所有UI拆分为独立组件） 
* 包含动画/交互效果

## 内容介绍：
1. 个人信息（姓名，学历，联系方式，个人简介）
2. 技术栈
3. 一些平台（b站，知乎，抖音，LeetCode，洛谷，GitHub，牛客网，Kaggle）
4. 一些奖项
5. 个人爱好
6. 个人项目介绍

## 需要说明的是：
1. 大部分是Gemini和DeepSeek写的，自己只做了很小一部分的修改 
2. 在这个项目的一开始我一点前端的知识也不理解，一点也没有学，并且我近期也没有学习的想法。如果我开始学习前端的知识，我会记录说明
